# Живой русский

Помогает писать по-русски ясно, выразительно и без переводного слога. Для сайтов, интерфейсов, писем, статей, инструкций, прозы и диалогов.

Скилл помогает выстроить мысль, найти точные слова и сохранить голос автора. При редактуре бережно обращается со смыслом: сохраняет факты, условия, сроки и степень уверенности. В диалогах учитывает характеры и отношения собеседников, в объяснениях — ход рассуждения, в интерфейсе — смысл действия.

## Установка

Скачай репозиторий и скопируй всю папку `zhivoy-russkiy` в одно из мест:

| | В проект | Для всех проектов |
|---|---|---|
| Codex | `.agents/skills/zhivoy-russkiy/` | `~/.agents/skills/zhivoy-russkiy/` |
| Claude Code | `.claude/skills/zhivoy-russkiy/` | `~/.claude/skills/zhivoy-russkiy/` |

## Вызов

В Codex:

```text
$zhivoy-russkiy
```

В Claude Code:

```text
/zhivoy-russkiy
```

Скилл использует контекст текущей задачи. При необходимости добавь пожелание к правке: например, «бережно, сохрани голос автора».
