# Живой русский

Переносимый скилл для **естественной русской речи** в Codex и Claude Code: сайты, интерфейсы, письма, статьи, объяснения, художественная проза и диалоги, в том числе игровые.

Он помогает писать по-русски сразу и убирать переводной слог при редактуре. Сохраняет смысл и подбирает речь под адресата, задачу, носитель и голос автора, бренда или персонажа. Сайт не обязан звучать как учебник, письмо — как реклама, а диалог — как инструкция. Приёмы советской редакторской и учебной традиции используются выборочно: конкретность, точность слова, выразительность, последовательность мысли. Скилл не навязывает идеологию, архаизмы или подражание автору.

**Версия 1.1.0 · Python 3.10+ нужен только для необязательных проверок.** Скилл работает как набор инструкций; он не дообучает модель и не требует книг, Telegram, API-ключа или доступа к GitHub.

## Быстрый старт

Скопируй всю папку `zhivoy-russkiy` в выбранное место:

| | В проект | Для всех проектов пользователя |
|---|---|---|
| Codex | `.agents/skills/zhivoy-russkiy/` | `~/.agents/skills/zhivoy-russkiy/` |
| Claude Code | `.claude/skills/zhivoy-russkiy/` | `~/.claude/skills/zhivoy-russkiy/` |

Вызови в Codex:

```text
$zhivoy-russkiy Отредактируй тексты этого сайта: убери переводной слог,
сохрани факты, условия услуги и голос бренда. Правка бережная.
```

В Claude Code:

```text
/zhivoy-russkiy Отредактируй это письмо: ясно и по-человечески,
сохрани просьбу, срок и отношения с адресатом.
```

Для проверки обнаружения попроси назвать путь загруженного `SKILL.md`. Подробности установки, обновления и интеграции с движком — в [инструкции](references/integration.md). Пути сверены с [официальной документацией Codex](https://learn.chatgpt.com/docs/build-skills) и [Claude Code](https://code.claude.com/docs/en/skills) 22.10.2026.

## Что меняется в тексте

**Черновик:** «Я не думаю, что это то, что мы должны делать прямо сейчас».

**Правка для сомневающейся Лиды:** «Не знаю, стоит ли сейчас за это браться».

Она по-прежнему сомневается. Реплика «Не трогай!» была бы сменой смысла, даже если она короче.

В диалоговом режиме у разных персонажей различаются не только слова, но и внимание, отношения и речевое действие. Мастер называет устройство и действие, ученица предлагает решение, диспетчер фиксирует условие допуска. Это пример карточек, а не правило о профессиях. Естественная русская речь может быть мягкой, строгой, длинной, современной, смешной или нарочито казённой — по задаче.

## Проверки

Из папки пакета:

```sh
python3 -m unittest discover -s tests -v
python3 scripts/quality.py compare examples/scene.before.json examples/scene.after.json
python3 scripts/quality.py lint examples/scene.before.json
```

Команды только читают данные. `compare` проверяет конкретный простой JSON-контракт, вставки, теги, переходы и лимиты. `lint` предлагает места для размышления; автоматических замен и списка запрещённых слов нет. Ни один скрипт не определяет художественное качество и не заменяет проверки игрового движка. Для Ren'Py, Ink, Yarn, Godot и Unity описаны правила работы, но их парсеры в пакет не входят.

Для других форматов агент сохраняет техническую структуру по правилам проекта. Сначала проверь одну сцену и её ветви, затем распространяй согласованные решения. Не отправляй проект внешним оценщикам без разрешения.

## Источники и права

Первоначальная версия опиралась на отдельные фрагменты Норы Галь, Перельмана и учебника под редакцией Ландсберга. Версия 1.1 дополнена по книгам из локальной выгрузки канала @sovuche, которую скачал пользователь: языковые пособия, научная популяризация и учебная литература. Библиография, прочитанные фрагменты и связь наблюдений с правилами — в [реестре источников](references/sources.md), состав файлов — в [инвентаре](references/corpus-inventory.json).

Извлечение текстового слоя не равно прочтению всей книги. Часть изданий изучена выборочно; есть сканы с ошибками OCR, повторные форматы одной книги и нерелевантные материалы. В подборке встречаются также дореволюционные и постсоветские издания: годы указаны отдельно. Это не репрезентативный корпус и не дообучение модели.

Все демонстрации написаны для пакета. Полные книги, сканы и чужие упражнения не распространяются. Лицензия MIT относится к оригинальным материалам и коду пакета, а не к внешним книгам и сайтам.

## Развитие

Предлагай улучшения вместе с контекстом: исходник, предполагаемая правка, канон, голос, эффект. Не добавляй универсальный запрет из одного неудачного оборота. Новое правило должно улучшать решение на проверяемом примере и не портить намеренный стиль. Для технических изменений запускай тесты; для редакторских — проверяй сохранение смысла и задания из `evals/`.

Скилл улучшает рабочий процесс, но не гарантирует качество любого ответа любой модели. Оценивай результат по конкретному тексту.
