# Мост: задание для редактуры сцены

Мост закрыт из-за повреждённого троса. Лида может принести ключ со склада. Если игрок отказывается идти за ключом, проход всё равно остаётся закрытым. Вера не знает, выдержит ли трос. Орлов ждёт результата осмотра к 18:00.

К игроку обращаются на «вы». Персонажи говорят друг с другом на «ты», но по официальной связи Орлов обращается на «вы». Их голоса описаны в [справочнике по диалогам](../references/dialogue.md).

Язык современный, без интернет-сленга. География мира, его история и политический строй не заданы. Не добавляй смерть, саботаж, нехватку денег, запрет на посещение склада, способ починки, автоматическое открытие моста или новый срок.

В `{player}` подставляется имя персонажа любого рода. Перестраивай фразу так, чтобы имя не требовалось склонять. В `{count}` подставляется число осмотренных опор; строка счётчика должна подходить для любого такого числа.

Поля `next` и `options` задают переходы между репликами. Валидатор проверяет их сохранность, а редактор — последовательность событий и смысл реплик. После согласия или отказа Орлов должен по-прежнему требовать проверки безопасности моста. Согласие пойти за ключом ещё не означает, что ключ принесли, и не разрешает проход.

Сцена придумана для демонстрации редактуры.
