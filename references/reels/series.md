# Серии и голос автора

У каждого ролика в серии есть свой вопрос и законченный ответ. Человек должен понять его, даже если не видел предыдущие части.

## Из урока в короткие ролики

Прочитай исходник или доступную расшифровку. Выдели вопросы, на которые там действительно есть ответы, выпиши для каждого факт, пример и вывод. Объедини повторы. Выбери фрагменты, которые можно объяснить самостоятельно, и добавь ровно столько контекста, сколько нужно новому зрителю.

Например, в уроке показаны выбор вопроса для бота, ввод списка услуг и проверка ответа. Отсюда получаются разные ролики:

- С чего начать: выбрать повторяющийся вопрос клиента.
- Что дать боту для ответа: актуальные сведения для этой задачи.
- Как проверить результат: сопоставить фактический ответ с исходным списком.

Календарь, CRM, автоматическую запись и замену сотрудника нельзя добавлять ради новых тем, если в источнике их нет.

Для серии из реальной работы подойдут вопрос, подготовка, сравнение, исправление или объяснение границы услуги. Проверь, произошёл ли эпизод и подтверждён ли итог. Не приписывай одному действию результат, на который могли повлиять другие причины. Если важен только смысл вопроса, вместо чужой переписки предложи подписанный учебный пример.

## Когда материала мало

По двум чашкам разного цвета и формы можно показать видимые различия. Для темы о доставке нужны условия доставки, об уходе — рекомендации мастера, о реакции покупателя — реальный разрешённый материал. Не растягивай один ответ в десяток роликов с новыми эпитетами.

В плане серии укажи вопрос зрителя, вывод и доступную наглядность каждого ролика. Полные сценарии пиши в заказанном объёме. Если пользователь просит только темы, не навязывай съёмочные планы.

## Как сохранить голос

Определи по образцам, как автор обращается к зрителю, насколько подробно объясняет, где шутит и какими терминами пользуется. Прочитай [карточку голоса](../voice.md), если нужна отдельная настройка. Переноси общие приёмы, сохраняя собственные слова автора; чужие узнаваемые реплики не копируй.

Во всех роликах должны совпадать названия продукта, условия, цена, обращение и способ связи. Если данные обновлены, используй последнее подтверждённое условие. Нужный термин поясни внутри текущего ролика, не рассчитывая на память зрителя.

При оценке после публикации используй только присланные показатели. Различай просмотр, сохранение и обращение по услуге. По одной публикации нельзя установить причину результата. Сопоставимые ролики и изменение одного существенного элемента позволяют осторожнее обсуждать гипотезу, но не доказывают её автоматически.
