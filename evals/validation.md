# Проверка пакета 2.1

## Техническая часть

```sh
python3 -m unittest discover -s tests -v
python3 scripts/check_package.py
python3 scripts/quality.py compare examples/scene.before.json examples/scene.after.json
python3 scripts/video.py compare examples/video.before.json examples/video.after.json
```

27 автоматических тестов проверяют реальные повреждения структуры, метаданных, типов, повторных вставок, порядка, тегов, лимитов и таймкодов; ошибки JSON и неподдержанный синтаксис; оценку времени с явным темпом; выборочную сборку промпта и режим диагностики. `check_package.py` проверяет локальные ссылки, маршруты, полноту тестовых входов и наличие хорошего исходника для каждого профиля. Оба инструмента сравнения работают только с описанными демонстрационными форматами.

Сцена содержит 15 строк и две ветви. Видеосценарий содержит три блока; менять можно только речь. Подсчёт слов и тесты структуры не доказывают смысловую эквивалентность и произносимость.

## Редакторская часть

[40 фрагментов](fragments.json) покрывают все 13 профилей; 14 исходников уже хороши. [26 регрессионных заданий](cases.json) дополнительно проверяют неоднозначность, модальность, цитаты, технические ограничения и вызов по контексту. Эти два набора не складываются в число состоявшихся модельных испытаний: полный сравнительный проход проведён только на 40 фрагментах.

[Сравнение версий](comparison.md) содержит фактические условия, результаты, обнаруженный риск и пределы выводов. [Шесть дополнительных задач](forward-check.json) проверены после уточнения правила о границах утверждения. Это не независимое доказательство прироста на всех жанрах.

## Расширенная проверка

[Десять полных заданий](extended.json) выполнены в трёх новых CLI-сессиях: без скилла, с 2.0 и с 2.1. [Анонимная оценка](extended-comparison.md) и все 30 ответов сохранены; длина не считается преимуществом. Это отдельный проход, не замена исторического сравнения 40 коротких фрагментов. [Проба инструкций humanizer-ru и ru-text](competitor-probe.md) на двух общих задачах не выдаётся за рейтинг продуктов.

[Проверка активации](activation.json): явный вызов 2.1 в установленном Codex CLI прошёл; Claude Code остановился до генерации из-за отсутствия входа. Автоактивация без явного упоминания не проверена.

## Ограничения

Автоматическое обнаружение без явного вызова, реальная игра, озвучка и production-сервис не проверялись. Активация в Claude Code не подтверждена из-за отсутствия входа. Формат инструкций и пути установки сверены с документацией. Любой реальный проект требует своих проверок. Скилл не дообучает модель; выборочное чтение книг не объявляется чтением всей подборки.

Версия 2.1 добавляет отдельную проверку выборочного подключения развёрнутой композиции. Весь новый набор и его источники проверены на целостность; результаты языкового сравнения не подменяются зелёным статусом технических тестов.
